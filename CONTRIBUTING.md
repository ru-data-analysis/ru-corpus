# Участие

- Предложения и ошибки — через issues; изменения — через pull request в ветку `main`.
- Перед pull request: `python3 scripts/scrub_check.py` должен проходить. В репозиторий не попадают частные документы, пути рабочей машины и ключи.
- Каждая цифра в примерах и тестах — из открытого документа демо-корпуса, с указанием документа и страницы.
