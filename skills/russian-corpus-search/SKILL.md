# Русский поиск по локальному корпусу

Навык описывает, как индексировать русскоязычные документы и искать по ним командой `ru-corpus`
(ядро `ru-corpus-kit` из этого репозитория). Поиск, OCR, таблицы и числа делает ядро; навык —
порядок работы и правила, которые не дают потерять качество.

## Быстрый старт

```bash
pip install -e "packages/ru-corpus-kit[tables,ocr]"     # из клона репозитория
# системные программы: poppler (pdftotext) и tesseract с языком rus
#   macOS:  brew install poppler tesseract tesseract-lang
#   Linux:  apt install poppler-utils tesseract-ocr tesseract-ocr-rus

python3 scripts/check_env.py                              # что установлено и что не хватает

cd папка-проекта
ru-corpus init --root ./документы --prefix "корпус/"      # создаёт corpus.toml
ru-corpus index                                           # реестр -> текст -> OCR -> леммы -> таблицы -> bm25
ru-corpus status                                          # что в индексе и что устарело
```

`ru-corpus index` инкрементален (sha256 документа): повторный запуск пересчитывает только новое и
изменённое. `--no-ocr` пропускает сканы, `--force` пересобирает всё.

## Команды

Каждая печатает один JSON-объект. Конфиг — `--config`, `RU_CORPUS_CONFIG` или ближайший `corpus.toml` выше по папкам.

| Команда | Что делает |
|---|---|
| `ru-corpus search "вопрос" --n 5` | доказательства: файл, страница, раздел, фрагмент, либо `verdict: "в корпусе нет"`; запрос из одного числа ищется по всем страницам |
| `ru-corpus page ДОК СТР` | точный текст страницы, метод извлечения (`ocr`), sha256, `origin` |
| `ru-corpus table --q "подпись строки" --year 2024` | ячейки таблиц: значение, единица, год, якорь «стр., таблица, строка, графа» |
| `ru-corpus doc ДОК` / `doc --find "слова названия"` | карточка документа: год и реквизиты акта из шапки |
| `ru-corpus number ДОК СТР "1 234,5"` | стоит ли число дословно на странице |
| `ru-corpus aggregate ДОК --column "..." [--column2 ... --where "..."]` | сумма, число, среднее, отношение сумм по графе таблицы |
| `ru-corpus calc "1 234,5 + 0,25"` | точная арифметика |

В агенте DeepSeek Harness те же действия — инструменты `corpus_*` плагина `dsh-ru-corpus`.

## Главные принципы

1. **Морфология важнее синонимов.** FTS5 не знает русских окончаний: «тариф» и «тарифы» — разные
   слова. Ядро приводит текст и запрос к леммам (pymorphy3, при его отсутствии — стеммер); это даёт
   основной прирост качества. Расширение сокращений добавляет мало, но снимает отдельные промахи.
2. **Запрос — OR, а не AND.** Слова вопроса редко стоят на одной странице; OR с ранжированием BM25
   поднимает страницы с большим числом совпадений.
3. **Две ветки поиска.** FTS5 по леммам страниц и BM25 по фрагментам; ветки сливаются по документам.
   Когда обе ниже порогов (`[search]` в `corpus.toml`), ответ — «в корпусе нет», а не лучшее из худшего.
4. **Сканы читает OCR.** Текстовый слой PDF всегда предпочтительнее; страницы без текста идут в
   tesseract (rus+eng), ориентация проверяется долей слов, известных pymorphy3. Цифру из скана
   сверяют с текстовым источником тех же данных; иначе — «скан, требует сверки».
5. **Число проверяется, а не вспоминается.** `number` и поиск по числу отвечают, где оно стоит дословно.
6. **Отраслевое — в профиле.** Уровни в заголовках таблиц, единицы, классы документов, словарь
   сокращений и слова для правки OCR подключаются профилем (`[profile]` в `corpus.toml`); без профиля
   работает общее ядро.

## Необязательно: kb-rag

Смысловые вопросы без общих слов с документом (перефразировки) можно дополнять векторным поиском
внешним плагином DeepSeek Harness `dsh-kb-rag` с русскими моделями. Это отдельный плагин: навык и
ядро от него не зависят, а «в корпусе нет» определяется только поиском `ru-corpus` — пустой или слабый
ответ векторного режима отсутствия не доказывает.

## Критерий готовности

`check_env.py` без ошибок, `ru-corpus status` показывает документы без `no_text` и `errors`, на
контрольных вопросах (методика — `references/ru-search.md`, раздел «Оценка») recall@5 не ниже 70 %.

## Когда навык не нужен

Англоязычная научная библиотека (хватит обычного векторного поиска) и разовый поиск по одному
документу — достаточно прочитать файл.
