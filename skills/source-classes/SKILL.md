# Классы источников

Одна и та же цифра весит по-разному в зависимости от того, откуда взят документ. Навык задаёт две
независимые оси и одну проверку.

## Оси

**Происхождение** (`origin_class`):

| Класс | Что это |
|---|---|
| `A` | первоисточник: файл с сайта того, кто издал или раскрыл документ (орган, издавший акт, или сама организация, раскрывающая информацию) |
| `B` | копия акта в правовой базе или у третьей стороны, реквизиты сверены с первоисточником |
| `C` | пересказ, новость, аналитическая сводка, любой производный текст |
| `?` | не определён: хост не входит ни в один список; решение принимает человек |

**Качество текста** (`quality`): `T` — родной текстовый слой; `O` — текст получен распознаванием
скана; `P` — слой неполный (текст не на всех страницах PDF); `N` — встроенный слой распознавания шумный
(цифры могли исказиться); `X` — текста нет, это скан без распознавания; `?` — неизвестно.

Правила по умолчанию — `references/classes.default.json`: списки хостов для `A`, `B`, `C`. Свои правила
передаются через `--rules`. Хост, которого нет в списках, получает `?`, а не `C`: автоматически снижать класс
и автоматически поднимать его одинаково опасно. Ручные решения записываются в `--overrides`
(`path,class,reason`), причина обязательна.

## Команды

```bash
python scripts/source_class.py textlayer <корпус> --out textlayer.csv
python scripts/source_class.py classify demo/corpus/MANIFEST.csv --out classes.csv \
       [--rules my-rules.json] [--overrides overrides.csv] [--root <корпус> --textlayer textlayer.csv]
python scripts/source_class.py summary classes.csv
python scripts/source_class.py gate registry/insights.json classes.csv [--allow-ocr] [--allow-class B] [--allow-unknown-quality]
```

`classify` читает реестр с колонками пути (`файл`, `rel_path`, `path` или `file`), `url_источника` или `url` и
`текстовый_слой` (как в демо `MANIFEST.csv`); BOM в заголовке допустим. Строки без файла (загрузка не удалась)
пропускаются и считаются отдельно. Если колонки текстового слоя нет, качество выводится из расширения:
html, xls, xlsx, doc, docx, txt, csv, json — `T`; png, jpg, tif — `O`; PDF и архивы остаются `?`, потому что
наличие текстового слоя у PDF по расширению не узнать.

### Текстовый слой PDF

`textlayer` разбирает сами PDF без распознавания и без внешних программ: считает страницы, потоки с
текстовыми операторами и изображения. Признак `text_layer`: `yes` (текст не менее чем на 90 % страниц),
`partial`, `no` (картинки без текста, скан), `ocr_layer` (невидимый текст поверх картинок: слой
распознавания, качество `N`), `unknown` (зашифрован, не разобран, страниц не найдено). Рядом хранится
`sha256` файла. `classify --textlayer` переводит признак в качество: `yes→T`, `partial→P`, `no→X`,
`ocr_layer→N`, `unknown→?`. Если вместе с `--root` хэш файла на диске изменился, качество становится `?`
с пометкой об устаревании: перезапустите `textlayer`. Это эвристика: по ней нельзя отличить хороший слой
распознавания от плохого, поэтому `ocr_layer` не допускается в точные выводы никогда.

Реестры, собранные краулером, часто отстают от диска: каталоги переложили, а пути в реестре остались старыми.
Параметр `--root <каталог корпуса>` сопоставляет путь из реестра с файлом на диске: `exact` (путь верен),
`basename` (найден однозначно по имени, путь заменяется на фактический), `ambiguous` (одноимённых файлов
несколько), `missing` (файла нет). В `classes.csv` исходный путь сохраняется в `registry_path`.

Список хостов своей организации (для класса `A`) держите в собственном файле правил вне открытого
репозитория и передавайте через `--rules`.

## Ворота для точных выводов

`gate` проверяет реестр выводов (`insight-registry`): запись с `certainty: definite` обязана иметь
`evidence`, и каждый документ из `evidence` должен иметь класс `A` и качество `T`. Параметры расширяют допуск
осознанно: `--allow-class B` пускает копии из правовой базы; `--allow-ocr` пускает качество `O` и `P`, но
только если в `evidence` указан `locator` (страница или фрагмент, который проверяет `verify_quotes`);
`--allow-unknown-quality` аварийно пускает `?` с предупреждением. Качество `X` и `N` в точные выводы не
пускается: скан сначала распознают, шумный слой заменяют. Нарушение значит одно из двух:
понизить вывод до `tentative` или найти первоисточник. Код возврата 1 при нарушениях.

Для `tentative`-выводов ворота только предупреждают о классах `?`, `C` и качестве `N`.

## Порядок

1. Снять манифест корпуса (`corpus-manifest`) и выполнить `classify`.
2. Разобрать все `?`: добавить хост в правила или записать решение в `overrides.csv`.
3. Перед `insight-registry ingest` и перед публикацией выводов выполнить `gate`.
4. В отчёте (`analysis-spec-first`) указать класс опорных документов в таблице §2.
