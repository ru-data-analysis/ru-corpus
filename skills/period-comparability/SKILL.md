# Сопоставимость периодов

Чаще всего «рост» или «падение» в аналитике по раскрытию оказывается следствием того, что в двух
периодах измерялось разное: поменялась форма, методика расчёта, перечень включаемых затрат, единицы
(тыс. руб. → млн руб., кВт·ч → МВт·ч). Навык вводит реестр таких разрывов и проверку до расчёта.

## Реестр разрывов

Файл `breaks.csv` в проекте анализа. Одна строка — один разрыв по одному показателю.

| Колонка | Смысл |
|---|---|
| `показатель` | название как в спецификации; `*` — разрыв затрагивает все показатели |
| `с_периода` | первый период (год), где действует новое определение |
| `тип` | `методика`, `форма`, `охват` или `единицы` |
| `что_изменилось` | одна фраза: было → стало |
| `коэффициент` | только для `единицы`: на что умножить значения до разрыва, чтобы получить новые единицы |
| `источник` | документ и страница, где разрыв подтверждён (обязательно) |

Шаблон — `references/breaks-template.csv`. Строки без источника скрипт отклоняет: разрыв, как и любая
цифра, должен опираться на документ корпуса (его находят командами `ru-corpus search` и `ru-corpus page`).
Не вносите в реестр разрыв «по памяти».

## Проверка до расчёта

```bash
python scripts/comparability.py check breaks.csv --metric "Структура затрат" --from 2022 --to 2025
python scripts/comparability.py validate breaks.csv
python scripts/comparability.py list breaks.csv [--metric "…"]
```

Разрыв затрагивает сравнение, если `с_периода` больше `--from` и не больше `--to`.

| Код возврата | Значение | Что делать |
|---|---|---|
| 0 | разрывов в интервале нет | сравнивать можно |
| 2 | есть разрыв типа `методика`, `форма`, `охват` или `единицы` без коэффициента | напрямую сравнивать нельзя: сузить интервал, найти пересчёт в документах или записать вердикт `open` |
| 3 | есть только разрывы единиц с коэффициентом | сравнивать можно после пересчёта; скрипт печатает коэффициент и период, к которому он применяется |

Пересчёт значений делайте через `ru-corpus calc`, а не в уме.

## Как применять в анализе

1. В спецификации (`analysis-spec-first`) укажите интервал периодов и запишите результат `check`.
2. В §0 рабочего отчёта строка «Сопоставимость периодов» принимает значения `пройдена`, `после пересчёта`
   или `не нужна (один период)`. Код 2 с вердиктом, отличным от `open`, — ошибка процесса.
3. В §4 отчёта («чего прогон не доказывает») обязательно перечислите разрывы, которые не удалось проверить:
   отсутствие записи в реестре не доказывает отсутствие разрыва.

## Что реестр не умеет

Он не находит разрывы сам. Он нужен, чтобы найденное один раз знание не терялось и проверялось
механически. Пополняется по мере чтения документов; пустой реестр означает «не проверялось», а не
«сопоставимо».
