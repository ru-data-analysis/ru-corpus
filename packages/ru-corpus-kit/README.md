# ru-corpus-kit

> Обзор проекта, быстрый старт и лицензии — в корневом [README](../../README.md) ([English](../../README.en.md), [中文](../../README.zh.md)).

Ядро инструментов русского корпуса документов: индексация (PDF, сканы, DOCX, XLSX…), поиск BM25 по леммам,
таблицы с графами и годами, точные числа, агрегаты. Консольная команда — `ru-corpus`. Каждый ответ —
JSON с документом, страницей и якорем, либо честное «в корпусе нет».

Ядро не привязано к отрасли: отраслевое (классы таблиц, уровни, энергетические единицы, словарь
сокращений) подключается профилем (`[profile]` в `corpus.toml`); в комплекте профиль `tso_disclosure`.

## Установка

Нужен Python 3.10+.

```bash
pip install -e packages/ru-corpus-kit            # ядро: pymorphy3, openpyxl
pip install -e "packages/ru-corpus-kit[tables]"  # + таблицы PDF с сеткой и широкие таблицы (pdfplumber, PyMuPDF)
pip install -e "packages/ru-corpus-kit[ocr]"     # + OCR сканов (Pillow, PyMuPDF); в системе нужен tesseract с языком rus
pip install -e "packages/ru-corpus-kit[rerank]"  # + кросс-энкодер (sentence-transformers) для --rerank
pip install -e "packages/ru-corpus-kit[office]"  # + .xls и .pptx без LibreOffice (xlrd, python-pptx)
```

Лицензия: `pymupdf` из extras `tables` и `ocr` — AGPL-3.0 или коммерческая (см. [THIRD_PARTY_LICENSES.md](../../THIRD_PARTY_LICENSES.md)).

Системные программы: `pdftotext` из poppler (если его нет, текст PDF берёт PyMuPDF), `tesseract` для сканов
(`brew install poppler tesseract tesseract-lang` / `apt install poppler-utils tesseract-ocr tesseract-ocr-rus`).

## Быстрый старт

```bash
cd мой-проект
ru-corpus init --root ./документы --prefix "корпус/"    # создаёт corpus.toml
ru-corpus index                                         # реестр -> текст -> OCR -> леммы -> таблицы -> bm25
ru-corpus status                                        # что в индексе и что устарело
```

`ru-corpus index` инкрементален: у каждого документа есть sha256; неизменённые файлы не пересчитываются,
изменённые проходят все стадии заново, удалённые убираются из индекса, копии с тем же sha256 не дублируются.
Прерванный запуск продолжается с того места, где остановился. Ключи: `--no-ocr` (пропустить сканы),
`--force` (пересобрать всё), `--stages text,lemma` (только указанные стадии).

## Команды

Все команды печатают один JSON-объект. Конфиг берётся из `--config`, переменной `RU_CORPUS_CONFIG`
или ближайшего `corpus.toml` выше по папкам.

```bash
ru-corpus search "выручка от передачи электроэнергии" --n 5   # доказательства: file, page, section, snippet
ru-corpus search "1 234 567,89"                               # запрос-число: поиск по всем страницам, пробелы разрядов не мешают
ru-corpus page d0001 1                                        # точный текст страницы + sha256 + origin
ru-corpus number d0001 1 "1 234 567,89"                       # стоит ли число дословно на странице
ru-corpus table --q "Потери электроэнергии" --year 2024       # ячейки таблиц: значение, единица, год, якорь «стр., таблица, строка, графа»
ru-corpus table --q "Ставка на содержание" --level СН2 --doc d0001 --page 3   # уровни — из профиля
ru-corpus aggregate d0003 --column "Мощность" --page "Реестр" # сумма/число/среднее/мин/макс; «Итого» сверяется, а не суммируется
ru-corpus aggregate d0003 --column "Стоимость" --column2 "Мощность"   # отношение сумм
ru-corpus aggregate d0003 --column "Мощность" --where "Наименование~Подстанция"
ru-corpus doc d0001                                           # карточка: год и реквизиты акта из текста шапки
ru-corpus doc --find "отчёт 2024"                             # поиск документа по названию
ru-corpus calc "1 234,5 + 0,25 - 10" --digits 2               # точная десятичная арифметика
```

Пример ответа `search` (демо-данные):

```json
{"ok": true, "q": "выручка от передачи электроэнергии", "verdict": "есть доказательства",
 "evidence": [{"doc": "d0001", "file": "корпус/reports/otchet_2024.pdf", "page": "1", "section": "основной текст",
               "sources": ["bm25", "fts"], "snippet": "…Выручка от передачи электроэнергии составила 1 234 567,89 тыс. руб.…"}],
 "facts": [], "scope": "all", "note": "поиск по всему индексу"}
```

Ловушка (вопрос, ответа на который нет в корпусе) возвращает `"verdict": "в корпусе нет"` с пустыми
`evidence` и сигналами отказа (`signals`): ответ без доказательства не выдаётся.

### Как устроен поиск

Две ветки: FTS5 по леммам страниц и BM25 по фрагментам (окно 96 токенов, перекрытие 16). Запрос — OR по
леммам с префиксом и синонимами из словаря. Ветки сливаются взвешиванием RRF по документам. Ответ «в корпусе
нет», когда обе ветки ниже порогов (`fts_coverage`, `bm25_best_doc`, `bm25_miss` в `[search]`).
`--rerank` (extras `[rerank]`) переупорядочивает фрагменты кросс-энкодером.

## corpus.toml

```toml
[corpus]
root = "документы"            # каталог с документами; относительные пути — от папки с corpus.toml
source_prefix = "корпус/"     # префикс ссылок в выводе: file и origin = префикс + относительный путь

[index]
dir = ".ru-corpus"            # kb.sqlite, bm25.sqlite, registry.csv
registry = []                 # готовые реестры CSV (id, rel_path, title, section, type, year, ext, sha256)
archive_registry = []         # реестры документов из архивов (в карточке from_archive = true)
# kb = "..."; bm25 = "..."    # пути к уже построенным базам
extensions = [".pdf", ".docx", ".xlsx", ".xlsm", ".xls", ".pptx", ".doc", ".txt", ".md", ".csv", ".json"]
exclude = ["**/.git/**", "**/node_modules/**"]
max_size_mb = 0               # 0 — без ограничения
ocr = true                    # сканы; нужен tesseract и extras [ocr]
ocr_dpi = 300
ocr_psm = 4
ocr_workers = 4
ocr_langs = "rus+eng"
tables = true                 # таблицы PDF с сеткой (extras [tables])
wide_tables = true            # широкие альбомные таблицы по координатам (extras [tables])
bm25_window = 96
bm25_overlap = 16

[search]
synonyms = ""                 # TOML-файл со словарём сокращений; пусто — словарь профиля
fts_coverage = 0.75
bm25_best_doc = 0.6
bm25_miss = 0.2
derived_sections = []         # разделы (первая папка) производного слоя: в выдаче ниже первичных
rerank = false

[profile]
name = ""                     # tso_disclosure | путь к каталогу профиля | пусто — только ядро
```

Словарь синонимов — TOML: сокращение (строчными) и фразы, на которые оно раскрывается:

```toml
[synonyms]
"тп" = ["технологическое присоединение", "трансформаторная подстанция"]
```

## Профили

Профиль — каталог с `profile.toml` (и файлами рядом). В нём то, чего нет в ядре: словарь сокращений
(`synonyms`), слова для правки OCR (`ocr_words`), шаблон номера акта (`act_no`), уровни в заголовках таблиц
(`[[levels]]`; «Всего» — в ядре), энергетические единицы измерения (`extra_units`), классы документов
(`[[classes]]`: год таких таблиц берётся из названия документа). Встроенный профиль
`tso_disclosure` — раскрытие информации сетевой организацией: баланс электроэнергии и мощности, потери,
структура затрат по форме 1831-э, предложение о ценах; уровни ВН/СН1/СН2/НН; единицы МВт, МВА, кВт·ч.
Свой профиль: `[profile] name = "путь/к/каталогу"`.

## Открыть уже построенный индекс без переиндексации

Схема `kb.sqlite` и `bm25.sqlite` совпадает со схемой прототипа, на котором ядро выросло, поэтому такой
индекс открывается через `corpus.toml`:

```toml
[corpus]
root = "/путь/к/корпусу"
source_prefix = "корпус/"
[index]
kb = "/путь/к/kb.sqlite"
bm25 = "/путь/к/bm25.sqlite"
registry = ["/путь/к/реестру.csv"]
```

Индекс, построенный не `ru-corpus index` (нет таблицы `kit_meta`), открывается только на чтение;
`ru-corpus index` на нём откажет, чтобы не испортить его.

## Что в индексе

- `docs`, `pages` (страница = страница PDF, лист XLSX, слайд PPTX; таблицы PDF — «N/тK» в `table_raw`);
- `pages_lemma` + FTS5 по леммам; разделы («Приложение № 3», «Таблица 2») протягиваются на следующие страницы;
- `docs_meta_text` — год периода, дата и номер акта из текста шапки, а не из имени файла;
- `table_cells` — ячейки таблиц: `label`, `year`, `level`, `half`, `unit`, `header` (путь графы), `value`, `raw`;
  `method = 'bbox'` — широкие таблицы, восстановленные по координатам;
- `bm25.sqlite` — фрагменты и FTS5.

## Ограничения

- Скан читается tesseract: цифры после OCR проверяйте командой `page` (поле `ocr`) и по оригиналу.
- В таблицах с графой, объединённой по вертикали («Итого» над строкой лет), графа наследует год соседней
  (приём протяжки шапки): год такой графы смотрите по якорю, а не по полю `year`.
- Запрос из одних аббревиатур, которых нет в тексте, даст «в корпусе нет»: синонимы расширяют запрос,
  но порог покрытия считается по словам самого вопроса.
- `.doc` читается через LibreOffice (если установлен), `.xls` — через xlrd или LibreOffice.

## Тесты

```bash
pip install -e "packages/ru-corpus-kit[tables,ocr,test]"
pytest packages/ru-corpus-kit/tests
```

Корпус для тестов генерируется в фикстуре: вымышленная организация «АО «Демо-Сеть»», вымышленные числа
(PDF — PyMuPDF, XLSX — openpyxl, DOCX — python-docx, скан — картинка с текстом). Тест OCR пропускается без tesseract.
