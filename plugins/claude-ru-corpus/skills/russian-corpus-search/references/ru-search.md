# Русский поиск: устройство, настройка, оценка

Справка к навыку `russian-corpus-search`. Все команды — `ru-corpus` из `packages/ru-corpus-kit`.

## Что видит поиск

| Источник | Что в индексе | Чего нет |
|---|---|---|
| Текст страниц и лемматизированный FTS5 | текстовый слой PDF, DOCX, XLSX (лист = страница), PPTX (слайд = страница), TXT/MD/CSV, OCR сканов | смысловые перефразировки без общих слов |
| BM25 по фрагментам | окна по 96 токенов с перекрытием 16 | то же |
| Ячейки таблиц (`table`) | таблицы PDF с сеткой и широкие альбомные по координатам; подпись строки, год, уровень, единица, якорь | таблицы без сетки и вне текстового слоя — только как текст страницы |

Правило: смысловой вопрос — `search`; точная цифра из таблицы — `table`; итог по графе реестра — `aggregate`;
проверка числа — `number` или `search` с самим числом.

## Запросы

Запрос превращается в OR по леммам с префиксом и синонимами из словаря:

- по умолчанию **OR**: страницы с большим числом совпадений всплывают за счёт BM25;
- сокращения расширяются фразой из словаря синонимов (в `corpus.toml`: `[search] synonyms = "файл.toml"`,
  в профиле — свой словарь);
- числа нормализуются: «1 234,5», «1234,5» и «1 234.5» ищутся как одно число;
- стоп-слова («какой», «где», «сколько») выбрасываются, иначе они съедают точность;
- запрос из одного числа не идёт в леммы, а ищется по всем страницам.

Словарь синонимов — TOML: сокращение строчными и фразы, на которые оно раскрывается.

```toml
[synonyms]
"тп" = ["технологическое присоединение", "трансформаторная подстанция"]
```

Запрос только из аббревиатур, которых нет в тексте, даст «в корпусе нет»: порог покрытия считается
по словам самого вопроса, а не по расширению.

## Пороги отказа

В `corpus.toml`, раздел `[search]`: `fts_coverage` (доля слов запроса, найденных в страницах),
`bm25_best_doc`, `bm25_miss`. Ответ «в корпусе нет» выдаётся, когда обе ветки ниже порогов; в ответе
есть `signals` — почему. Если находится лишнее — поднимать пороги, если пропадает нужное — снижать, каждый
раз проверяя на контрольных вопросах и вопросах-ловушках (см. «Оценка»).

`derived_sections` — разделы (первая папка), где лежат производные отчёты: в выдаче они идут ниже первичных документов.

## OCR: чек-лист

1. Текстовый слой PDF всегда предпочтительнее; OCR запускается для страниц без текста.
2. Ориентация: доля слов, известных pymorphy3. Низкая доля — страница повёрнута; пробуются исходная
   ориентация, 180°, 90° и 270°, выбирается лучшая. Число символов для этого не годится: перевёрнутая
   страница тоже даёт «читаемые» слова.
3. tesseract с `rus+eng`, 300 dpi, `psm 4` (`ocr_langs`, `ocr_dpi`, `ocr_psm` в `corpus.toml`).
4. После OCR — правка смешения алфавитов («тaриф» с латинской «a») и редких словоформ по частотным
   соседям; список слов профиля (`ocr_words`) помогает на отраслевых терминах.
5. Метрика качества OCR — доля слов вне словаря pymorphy3 на выборке страниц: должна быть единицы процентов.
6. Цифры скана проверять командой `page` (поле `ocr`) и по оригиналу.

## Метаданные и разделы

- Год и номер акта берутся из текста шапки, а не из имени файла: `ru-corpus doc ДОК`.
- Год в имени файла не равен году действия: акт, подписанный в конце года, часто действует на следующие годы.
- Разделы («Приложение № N», «Таблица N») протягиваются на следующие страницы.
- В таблицах с графой, объединённой по вертикали («Итого» над строкой лет), графа наследует год соседней:
  год такой графы смотрите по якорю ячейки, а не по полю `year`.

## Оценка качества

1. Составить 30 вопросов с известными документами-ответами по разным видам документов; добавить 5–10
   вопросов-ловушек, ответа на которые в корпусе нет.
2. Считать recall@5 и MRR@10 для режимов: точные словоформы, леммы, леммы + синонимы.
3. Ловушки должны давать `verdict: "в корпусе нет"`.
4. При росте корпуса пересчитывается IDF, и метрика может немного упасть без ухудшения поиска:
   сравнивать на одном и том же наборе документов.
5. Промахи разбирать поштучно: чаще всего мешает отсутствие слова на странице, конкуренция однотипных
   документов за разные годы или аббревиатура без синонима.

Ориентир: точные словоформы заметно хуже лемм; леммы — не ниже 70 % recall@5. Ниже — искать причину.

## Обновление индекса

`ru-corpus index` сам находит новые, изменённые и удалённые файлы. После правки словаря синонимов
пересборка индекса не нужна (запрос расширяется на лету); после смены профиля, `ocr_*` или окна BM25 —
`ru-corpus index --force`. Состояние: `ru-corpus status`.

## Необязательно: векторный поиск (kb-rag)

Внешний плагин DeepSeek Harness `dsh-kb-rag` с русскими эмбеддингами (например `ai-forever/ru-en-RoSBERTa`
и русский кросс-энкодер) добавляет смысловые совпадения. Он не входит в этот репозиторий, не делает OCR
(сканы в нём пустые) и не доказывает отсутствие: «в корпусе нет» определяется только `ru-corpus search`.
Размерность векторов фиксируется при загрузке документов: смена модели требует пересборки его индекса.
Повторное ранжирование кросс-энкодером есть и в ядре: `ru-corpus search --rerank` (extras `[rerank]`).
