# Рабочий отчёт о прогоне

> Удалить строки с `>`. Один файл на один прогон: `<гипотеза>/<прогон>.run.md`.

## 0. Привязка

| Поле | Значение |
|---|---|
| Гипотеза | `h-…` |
| Спека | `s-…` v1, хэш `sha256 …` |
| Спека заполнена до расчёта | да / нет |
| Дата прогона | YYYY-MM-DD |
| Исполнитель | модель или человек |
| Статус | завершён / упал / частично |
| Хэш корпуса | `corpus_hash …` (навык `corpus-manifest`, команда `hash`) |
| Сопоставимость периодов | пройдена / после пересчёта / не нужна (один период) (навык `period-comparability`) |

## 1. Что запущено

> Пути, команды, версии, хэши входов и выходов. Здесь можно и нужно.

- Команда: `…`
- Входные данные: …, хэш …
- Артефакт: `…`
- Окружение: …
- Затраты: `cost: wall_s=…; cpu_s=…; max_rss_mb=…` (навык `cost-log`, команда `line`)
