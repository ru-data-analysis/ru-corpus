# Демо-корпус ru-corpus

Небольшой публичный корпус для проверки ядра `ru-corpus` «из коробки»: 15 официальных актов органов власти
по электроэнергетике и тарифному регулированию, плюс вымышленный синтетический набор «АО «Демо-Сеть»».
К корпусу приложены контрольные вопросы с проверенными ответами.

## Правовое основание

Официальные документы государственных органов (законы, постановления, приказы, предписания, решения и т. п.) не являются
объектами авторского права — п. 6 ст. 1259 Гражданского кодекса РФ. Все 15 файлов получены только с сайтов органов власти
(`*.gov.ru`, региональные официальные порталы); сайты компаний и агрегаторы не использовались. Файлы лежат в репозитории
без изменений, ссылка на источник и SHA-256 каждого — в `corpus/MANIFEST.csv`. Документы приведены для проверки ПО и
не заменяют официальную публикацию: за актуальной редакцией обращайтесь на сайт органа.

Из корпуса исключены акты Москвы и её регулятора, а также любые документы, в тексте которых встречаются названия
организаций, чьи данные не должны попасть в публичный набор (проверка — `check_corpus.py`, по извлечённому тексту
и результату OCR). Слово «Москва» в федеральных актах встречается только как место подписания.

Полные реквизиты, заголовки и URL — `corpus/MANIFEST.csv`. Общий размер ≈ 11,2 МиБ (лимиты: файл ≤ 8 МиБ, корпус ≤ 30 МиБ).

Что не вошло, и почему:

* **XLSX-приложений нет.** В разделе документов Минэнерго (≈650 просмотренных записей) файлов Excel нет, а у региональных
  регуляторов и ФАС приложения к актам, найденные при подготовке, опубликованы только в PDF. Excel-ветку ядра покрывает
  синтетика (`corpus/synthetic/registers/reestr_2024.xlsx`).
* **Скан без текстового слоя один** — приказ Минэнерго № 745. Дата и номер акта на самом скане нечитаемы для OCR
  (рукописные вставки), поэтому реквизиты в манифесте взяты из карточки документа на сайте Минэнерго.
* **Московские документы не брались** по условию состава корпуса.

## Синтетика «АО «Демо-Сеть»»

Вымышленная организация и вымышленные числа: отчёт, широкая таблица тарифов, скан, XLSX, DOCX, TXT.
В git не хранится — создаётся генератором из тестов пакета:

```bash
python3 demo/make_synthetic.py        # -> demo/corpus/synthetic/
```

## Как пересобрать

```bash
python3 demo/fetch.py                 # скачать файлы по MANIFEST.csv и сверить SHA-256 (--verify — без сети)
python3 demo/make_synthetic.py        # синтетика
cd demo && ru-corpus index            # индекс в demo/.index/ (в git не попадает); сканы распознаются tesseract
python3 check_corpus.py               # размеры, хеши, отсутствие запрещённых упоминаний в тексте
python3 check_questions.py            # автопроверка вопросов, отчёт — questions/CHECK.md
```

`fetch.py` использует `curl` и вежливые паузы между запросами (для minenergo.gov.ru — 5 с). Для PDF ФАС, которые сайт генерирует на лету, байты меняются только датой создания, поэтому в манифесте есть
второй хеш `sha256_без_дат_pdf`. Если орган заменил файл,
хеш не совпадёт: загруженный файл сохраняется с суффиксом `.mismatch`, а строку манифеста нужно обновить осознанно.
Файлы `.index/`, `corpus/synthetic/` и временные файлы закрыты `demo/.gitignore`.

## Контрольные вопросы

`questions/questions.json` — пять вопросов с ответами из документов корпуса и одна ловушка («в корпусе нет»).
Каждое значение проверено командой `ru-corpus number` (найдено дословно на указанной странице); вопросы по широкой
таблице и по итогу графы дополнительно проверены `ru-corpus table` и `ru-corpus calc`. Результаты — `questions/CHECK.md`.

Известное ограничение (зафиксировано в CHECK.md): отказ «в корпусе нет» зависит от лексического пересечения вопроса с
корпусом — формулировка ловушки с общими словами («услуги по передаче электрической энергии») получает ложное
«есть доказательства» из предписаний ФАС, короткая формулировка — корректный отказ.
