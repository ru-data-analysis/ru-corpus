# demo/corpus

Документы демо-корпуса. Реальные акты лежат в папках `gov/`, `minenergo/`, `fas/`, `regions/` и описаны в
`MANIFEST.csv` (орган, реквизиты, URL источника, SHA-256, размер, текстовый слой, широкие таблицы).
Папка `synthetic/` создаётся скриптом `demo/make_synthetic.py` и в git не хранится.
Подробности — `demo/README.md`.
